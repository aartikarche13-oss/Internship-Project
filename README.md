# SmartStudy – Multi-page Student Study Planner

A responsive student productivity website built using HTML5, CSS3 and vanilla JavaScript.

## Pages
1. Dashboard – task and study overview
2. My Tasks – add, search, filter, complete and delete tasks
3. Subjects – manage study subjects
4. Study Timetable – schedule weekly study sessions
5. Calendar – view dates and pending deadlines
6. Study Notes – create and delete revision notes
7. Progress – view completion statistics
8. Goals – set targets and track milestones
9. Settings – theme, data export and reset

## Run in VS Code
1. Extract the ZIP file.
2. Open the `SmartStudy_MultiPage` folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Use the left navigation menu to visit the other pages.

## Technologies
- HTML5
- CSS3 (responsive layout)
- JavaScript
- Browser Local Storage

## Data note
This is a front-end project. Data is saved in the browser on the same origin/device. It is not a cloud database and does not provide real user authentication. Browser storage can be cleared by the user. For a production application, add a backend, database, authentication and server-side validation.
